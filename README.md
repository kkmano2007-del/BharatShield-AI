# 🛡️ BharatShield AI

## AI-Powered Digital Safety Investigation Assistant

BharatShield AI is an AI-powered digital safety investigation assistant designed to help users analyze suspicious messages and links.

The application uses a modular multi-agent architecture where specialized agents investigate different aspects of potential digital threats, including social engineering, financial risks, suspicious links, identity impersonation, and scam patterns.

---

## 🚀 Features

- 🧠 Social Engineering Detection
- 💳 Financial Risk Analysis
- 🌐 Suspicious Link Analysis
- 🎭 Identity and Impersonation Detection
- 🧩 Scam Pattern Detection
- 🚨 Risk Signal Detection
- 📊 Risk Score Calculation
- 🤖 AI-Powered Investigation
- ⚖️ Evidence and Uncertainty Analysis
- 🛡️ Safe Recommended Actions

---

## 🤖 Multi-Agent Architecture

BharatShield AI uses multiple specialized agents.

### 🚨 Risk Signal Agent

Detects suspicious indicators such as:

- Urgency
- Threats
- Financial keywords
- Suspicious actions
- Links

### 🧠 Social Engineering Agent

Detects possible manipulation techniques such as:

- Artificial urgency
- Fear-based language
- Threats
- Pressure to take immediate action

### 💳 Financial Risk Agent

Analyzes messages for possible:

- Payment requests
- Money transfers
- UPI-related requests
- OTP requests
- PIN requests
- Password requests
- Sensitive financial information

### 🌐 Link Analysis Agent

Extracts and analyzes URLs for suspicious characteristics.

### 🎭 Identity Agent

Detects references to organizations and platforms that may potentially be used for impersonation.

### 🧩 Scam Pattern Agent

Combines findings from multiple agents to identify potentially concerning patterns.
